# GitHub Clone

A modern GitHub profile search and explorer web application built with React.  
Search GitHub users and view their public profile details including repositories, followers, company, location, and social links.

---

## Features

- Search GitHub users by username
- View user profile information (avatar, bio, join date, company, location)
- Display user's repositories, followers, and following count
- Responsive and clean UI inspired by GitHub
- External links to GitHub profile and Twitter
- Error handling for invalid usernames

---

## Tech Stack

- React.js
- Axios for API calls
- React Icons for UI icons
- CSS Flexbox & Grid for responsive layout
- GitHub REST API v3
